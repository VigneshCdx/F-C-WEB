## Why I built this

Starting college usually means figuring out a lot of small things at once.

Where is the library? Which clubs can I join? When is an event? Who can I ask for help? What should I learn first?

Freshers' Companion is a prototype built around that idea. Instead of keeping this information across different places, the app brings it into one campus focused interface.

## What the prototype covers

- Campus information and facilities
- Mentor discovery and matching
- Learning paths for freshers
- Personalized alerts
- Events and campus activities
- Peer community discussions
- Badges and onboarding progress
- Campus FAQs
- Mobile responsive navigation
